# 🌿 HastaShilpa

*A minimal Android application inspired by handmade artistry and modern design.*

---

## ✨ About

HastaShilpa is an Android application created to showcase handmade crafts and artisan products through a clean and simple digital experience.

The project focuses on elegant UI design, smooth navigation, and accessibility for users exploring handmade collections.

---

## 📱 Features

* 🔐 User Authentication
* 🛍️ Product Listings
* 📂 Category Browsing
* 🎨 Clean User Interface
* ⚡ Smooth Android Experience

---

## 🛠 Tech Stack

* Kotlin
* Android Studio
* Firebase
* XML

---

## 🚀 Installation

```bash
git clone https://github.com/Thahira05/HastaShilpa2.git
```

Open the project in Android Studio and run the application.
